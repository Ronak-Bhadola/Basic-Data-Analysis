# Sales Data Analysis

## Project Overview

This project analyzes the Sample Superstore dataset to understand sales performance, profitability, customer behavior, product performance, and regional trends.

Using Python and its data analysis libraries, I performed data cleaning, exploratory data analysis (EDA), and data visualization to identify patterns and generate meaningful business insights.

## Objectives

- Analyze overall sales, profit, and profitability.
- Identify the best- and worst-performing products and categories.
- Compare sales and profit across different regions and customer segments.
- Understand the relationship between discounts and profitability.
- Analyze monthly and yearly sales trends.
- Compare shipping modes based on sales, profit, and order volume.
- Present findings through data visualizations and business insights.

## Tools and Technologies

- **Python** — Data analysis and calculations
- **Pandas** — Data manipulation and analysis
- **NumPy** — Numerical operations
- **Matplotlib** — Data visualization
- **Seaborn** — Statistical visualization
- **Plotly** — Interactive visualizations
- **Jupyter Notebook** — Writing and executing analysis code

## Dataset

This project uses the Sample Superstore dataset, which contains transaction-level information about orders, customers, products, sales, discounts, profits, and shipping.

The dataset is included in this repository as `Sample_Superstore.csv`.

## How to Run the Project

### Prerequisites

- Python 3.9 or later
- Jupyter Notebook or VS Code with the Jupyter extension

### 1. Clone the repository

```bash
git clone https://github.com/Ronak-Bhadola/Basic-Data-Analysis.git
```

### 2. Navigate to the project directory

```bash
cd Basic-Data-Analysis
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

### 4. Open the notebook

```bash
jupyter notebook Sales_Analysis.ipynb
```

Run the notebook cells from top to bottom. Make sure `Sample_Superstore.csv` is in the expected location so the notebook can load the dataset successfully.
